# Land!
Land! is a visual inspiration community for discovering and sharing images made by people. AI-generated images are not allowed.
Features

Sign-up and log-in demo
Browse image posts by category
Search posts
Create image posts
Report posts

# Run locally
Open index.html in a browser. The app is a standalone HTML file with CSS and JavaScript included.
Important limitations
This is a front-end prototype, not a production-ready service:

Accounts and passwords are stored in the browser and are not secure. Don’t use real passwords.
Posts are only available in the current browser session.
Reporting does not send reports to a moderation team.
The app does not detect AI-generated images or enforce its rules.
